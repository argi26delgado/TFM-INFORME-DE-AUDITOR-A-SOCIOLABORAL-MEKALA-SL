# TFM-INFORME-DE-AUDITOR-A-SOCIOLABORAL-MEKALA-SL
Auditoría sociolaboral de MEKALA S.L. sobre el ejercicio 2023. Se analizaron 13 áreas de riesgo mediante revisión documental, evaluación del control interno, pruebas de cumplimiento, muestreo y análisis de evidencias. Se identificaron salvedades y contingencias y se propusieron medidas para mejorar el cumplimiento sociolaboral y reducir riesgos.
